# Blind Q26 repartition checkpoint

This directory contains compact, non-source-level checkpoints for the final blind Q26 repartition used in Paper II. The published Q26 association labels were withheld during clustering and used only afterwards to score the recovered structures.

The source Q25/Q26 catalogues and star-level truth-label tables are **not redistributed** here. `q26_run_summary.json` records the final S1 -> S3 -> S2 group counts and code hash; `q26_blind_summary.csv` records the post-hoc best-match Jaccard checkpoints reported in the manuscript.
